# Guild Scam: Wait, is that a DRAGON?! — 網頁試玩版

用瀏覽器直接玩，不用下載、不用安裝。

**→ https://nba9001-sys.github.io/guild-scam-play/**

目前版本：**v1.75.0**

---

## 這一版有什麼

- **換武器的時候可以用滑鼠了**：指著卡片就看得到完整詞條，點一下展開兩把並排比較
  （TAB 照舊有效）。
- **五階（終局）職業來了**：打退王有機會掉「王的遺物」，帶著它就能轉「龍裔」或
  「幕後會長」。兩個都是**純升級**，不用挑，撿到哪個轉哪個。
  ⚠️ 立繪還在畫，現在轉過去會沿用轉職前的圖。
- **三隻遠程怪換成新特效**：吐泡史萊姆的酸液、哥布林法師的火球、骷髏弓箭手的黑暗冰箭。
- **衝刺怪要衝過來之前會渾身冒紅光**，越紅就是越接近衝出去。
- **標題頁右下角可以直接關音樂**，設定裡也多了「音量」分頁（音樂／音效兩條滑桿）。
- **第一次換武器會提醒你「武器決定技能，按 TAB 看詳細」**，
  而且那句話會一直留在面板上，不會自己消失。想每次都看，設定裡可以勾回來。
- **四轉大招不再拖著前面的小招**：祕術騎士場上只會有暴風雪、流星雨、雷霆風暴；
  戰法師只有連射；劍聖只有劍氣。以前那三組會連前兩階一起開，畫面被雷電球洗版。
- **男角四階立繪到齊**（四轉男女兩套都有了）。
- **等級好練多了**：每一級的經驗需求整條砍掉三分之一。
  一局打完大概會到 **Lv74**（以前是 Lv65）。
- **打贏龍之後，畫面上方會一直提醒你可以收手**（ESC →「設定」→ 收手回公會，
  戰利品全部帶走）。不想走的話留下來打滿 25 分也行。
- **四轉男女兩套美術都到齊了**。
- 難度越高，帶回公會的金幣越多（難度 5 一場約等於難度 1 的 2.9 場）。
- **四轉來了**：祕術騎士、戰法師、劍聖、渾沌行者、天災行者，
  外加隱藏的第五階「徽章收集者」。六個職業都有自己的立繪與走路圖。
- 四轉的門很窄：除了屬性門檻，還要身上帶著對應的**徽章**（原本的「之證」改名）。
  徽章只從寶物箱出，**沒有任何一枚是轉職送的** —— 局外「排除寶物」是你唯一推得動的槓桿。
  五枚集滿可以轉「徽章收集者」，不看屬性。
- **男女主角都有了**（一～三階）。角色創建時選「男」或「女」，
  場上的角色、立繪、頭像、圖鑑、轉職畫面全部會跟著換。
- 打完龍之後可以**提前收手回公會**（戰利品全部帶走），不用再打滿 25 分。
- 出怪節奏整體加快，龍提前到第 15 分出場。

## 這個 repo 是什麼

只有**可以玩的成品**，沒有原始碼、沒有美術原檔。
每次更新都是「砍掉重來一個 commit」再 force push —— 一版 100 MB，
不砍的話推個十次這個 repo 就一 GB 了。

## 跟桌面版（.exe）的差別

畫質是**有損壓縮**過的，為了把體積壓下來。並排比對過，肉眼看不出來
（平均色差 1.8/255）。桌面版的原檔完全沒有動。
背景音樂也從 320k 降到 128k（音效沒動 —— 破音在短音上最明顯）。

- 存檔存在**瀏覽器裡**，換瀏覽器或清快取就沒了
- 第一次要下載約 106 MB，進度條跑完才會進遊戲；之後瀏覽器會快取
- 網頁版比桌面版慢也比較吃記憶體，覺得卡是正常的
- 單執行緒版本，所以不需要任何特殊的伺服器標頭

## 回報問題

玩到覺得怪的地方，講「在第幾分鐘、做了什麼、看到什麼」最有用。
