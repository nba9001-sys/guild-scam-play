## 這一版有什麼

- 設定新增「特效品質」（自動／高／中／低）與「顯示 FPS」：電腦跟不上的時候，會自動減少純裝飾的特效（死亡爆散、傷害數字、嗜血粒子）；怪物、子彈與攻擊預警不會少。在設定的「螢幕」頁，局內按 Esc 也調得到。
- 巨劍士（女）的走路圖重新去背，白頭髮不再缺角。
- 牧師（女）的走路圖換成重新生成的版本（一圈 20 張、更順）。

## 怎麼玩

- 鍵盤：WASD 移動、Esc 手冊、TAB 看武器詳細／戰鬥詳細、Enter／空白確認
- 手把：左蘑菇頭移動、A 確認、B 返回、X 排除／替換／戰鬥詳細、Y 詳細、
  L／R 換分頁或換一把、L2／R2 走欄位或走階級／品質、右蘑菇頭捲動
  （結算頁的 Y 是長按結算；戰鬥詳細開著時方向鍵上下是捲動）

存檔存在瀏覽器裡，換裝置不會帶著走。
