## 這一版有什麼

- ★ **撿到的那一個會發金光了** ★ 換輔助武器、換寶物那兩頁，
  在這之前「剛撿到的」跟「身上的」唯一的差別是上面那塊小標題籤 ——
  而你在那一頁忙著比數值，根本不會去讀標題。
  現在撿到的那一張卡（那一顆寶物）有金色光暈、金框，還會往上飄金色光點。
- ★ **勾選框改成真的打一個「✔」** ★ 手冊總覽的「拾取偏好」那一排有八顆，
  以前是內建的小圓點，勾了跟沒勾在 1920×1080 上只差三個像素。
  「輔助武器不更換」「寶物滿了不更換」那兩顆也一樣。
- **手把走到勾選框上看得出來了**：以前完全沒有反應，現在有一圈金色焦點框。
- ⚠️ **版權頁上那一行紅字還在**：去背用的 RMBG-2.0 授權是 CC BY-NC 4.0，
  只授權非商業使用。要賣這款遊戲得先解決這一項。

## 怎麼玩

- 鍵盤：WASD 移動、Esc 手冊、TAB 看武器詳細／戰鬥詳細、Enter／空白確認
- 手把：左蘑菇頭移動、A 確認、B 返回、X 排除／替換／戰鬥詳細、Y 詳細、
  L／R 換分頁或換一把、L2／R2 走欄位或走品質、右蘑菇頭捲動
  （結算頁的 Y 是長按結算）

存檔存在瀏覽器裡，換裝置不會帶著走。
