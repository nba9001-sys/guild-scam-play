網頁試玩版 v1.75.0 —— 更新到 guild-scam-play
============================================

這個資料夾就是 https://github.com/nba9001-sys/guild-scam-play 的內容。
我已經把裡面的遊戲檔案換成 v1.75.0 了，你只要推上去。


怎麼更新
--------
  雙擊 **push_to_play_repo.bat** → 一路 Enter。

  它會把 .git 砍掉重做，變成**一個全新的 commit** 再 force push。
  那是刻意的：一版 100 MB，不砍的話推十次這個 repo 就一 GB。

  推完等一兩分鐘，網址就是新版：
  **https://nba9001-sys.github.io/guild-scam-play/**

  ⚠️ Pages 的設定（Settings → Pages → main / root）你上次已經開過了，
     這次不用再動。


想先自己看一眼
--------------
  雙擊 **start_local_test.bat** → localhost:8123。
  ⚠️ **不要直接雙擊 index.html** —— 瀏覽器禁止 file:// 載入 .wasm，
     只會看到一片黑，而且沒有任何錯誤訊息。


這一版給試玩的人看的重點
------------------------
  · 創角時選男或女，**兩套美術都有了**（十六個職業各一套）
  · 打完龍可以提前收手回公會，戰利品全部帶走
  · 節奏加快，龍第 15 分出場
  · 換寶物不會再扣現在的血


⚠️ 一定要先跟試玩的人講
-----------------------
  · **存檔存在瀏覽器裡**。換瀏覽器、換電腦、清快取 → 存檔就沒了。
  · 第一次要下載約 106 MB，進度條跑完才會進遊戲。
  · 網頁版比桌面版慢，覺得卡是正常的。
  · 畫質比桌面版略軟（有損壓縮，為了壓體積）。桌面版完全沒受影響。


我驗到哪裡
----------
用無頭 Chromium（軟體渲染）真的開起來了：
標題畫面正常、**JavaScript 錯誤 0 個**、
資料全載得進來（職業 16ㆍ武器 46ㆍ詞條組 22ㆍ敵人 22ㆍBoss 5）。

沒驗到、要靠試玩的人回報：實際戰鬥幀率、音效與音樂、手把、存檔。


幾個數字
--------
  · 總共約 106 MB（index.pck 63.4、index.wasm 39.5、其餘 0.4）
  · GitHub 單檔上限 100 MB —— 過得去，但 63 MB 已經超過 50 MB 的警告線。
    美術再加下去就會超過，到時候要改用 Git LFS 或搬去 itch.io。
  · Pages 流量軟上限 100 GB／月 ÷ 106 MB ≒ **每月約 900 人次**。試玩夠用。


★ 這個資料夾的名字還停在 GuildScam_play_v1.51.0 ★
它其實是「那個 repo 的本機副本」，不是某一版的快照 ——
每次更新都是換裡面的檔案，資料夾本身不會換。
要我改成不帶版號的名字（例如 GuildScam_play_repo）跟我說一聲，
那支 .bat 走的是自己的所在位置，改名不會壞掉。
